# Visions of Grandshelt 0.2.63 beta

This update supports FINAL FANTASY RESONANCE on Windows Steam build 24250053.

- During **Visit Siren**, use **Story** to find the entrance door and the way through Siren’s Tower. Story also guides you back from the summit and to the save point for the return to the entrance.
- Both tower lifts appear under **Exits, doors and ladders** when you can reach them. When a lift stops, you can choose a new target and start guidance from the platform, including to the side-ledge chest.
- **Objects** lists tower chests and pickups with a verified approach. The pot appears while its interaction is available.

## Update

Close the game. In [Amethyst Accessibility Mod Manager](https://github.com/RealAmethyst/AccessibilityModManager), choose **Visions of Grandshelt** from **Buu’s Mods** and select **0.2.63 Beta**. For a manual update, extract the Windows ZIP into the Steam game folder. Install the [Microsoft .NET 9 Desktop Runtime for Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/9.0), start your screen reader, then launch from Steam.

For a manual upgrade from 0.2.52, see the [instructions for removing the retired recordings](https://github.com/buu420/visions-of-grandshelt/releases/tag/v0.2.54).

## Beta testing

Copied-save runs with scripted controller input reached the interaction prompts for all seven tower chests, all three Tablet Shards, and the pot. Both lifts were tested in both directions. All 33 automated test suites passed. The startup log identifies the reader as `0.2.63-dev`.

If a route fails, give the room, your current objective, the target you selected, and the last announcement. Let us know if you were on a lift or using auto-walk. Include `ResonanceAccess.log` if available. [Report a bug](https://github.com/buu420/visions-of-grandshelt/issues)
