# Visions of Grandshelt 0.2.60 beta

This update supports FINAL FANTASY RESONANCE on Windows Steam build 24250053.

- During **Save the King of Grandshelt**, Story guides you up the west staircase and along the gallery. Follow the spoken direction through the gallery door and restart auto-walk to reach the ladder. Hold **Up** when prompted to climb. Story picks up in the east wing, where the next doorway can still need manual steering.
- Auto-walk pauses before the signed Antlion quicksand and warns you to cross by chocobo. Your pickup stays selected so you can go around and resume. Walking into the quicksand on foot can still trigger the encounter.

The new story directions and quicksand prompts use English.

## Update

Close the game. In [Amethyst Accessibility Mod Manager](https://github.com/RealAmethyst/AccessibilityModManager), choose **Visions of Grandshelt** from **Buu's Mods** and select **0.2.60 Beta**. For a manual update, extract the Windows ZIP into the Steam game folder. Install the [Microsoft .NET 9 Desktop Runtime for Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/9.0), start your screen reader, then launch the game from Steam.

For a manual upgrade from 0.2.52, see the [instructions for removing the retired recordings](https://github.com/buu420/visions-of-grandshelt/releases/tag/v0.2.54).

## Beta testing

All 33 test suites passed. A copied game verified the west staircase, gallery door, and ladder handoff. The same build paused outside the Antlion trigger on the reported pickup route. Deliberately crossing on foot still started the fight. The startup log identifies this reader as `0.2.60-dev`.

If you get stuck or miss an announcement, include the area, selected target, and last announcement in [GitHub Issues](https://github.com/buu420/visions-of-grandshelt/issues).
