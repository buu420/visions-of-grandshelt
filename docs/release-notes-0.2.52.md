# Visions of Grandshelt 0.2.52 beta

This is the first public beta of Visions of Grandshelt for FINAL FANTASY RESONANCE on Windows Steam build 24250053.

- Read menus, visible equipment slots, tutorials, dialogue and battle commands with a screen reader. Review party HP, MP, Limit gauges and status effects.
- Browse nearby people, objects and exits. Follow Story or a selected destination with a positional beacon or auto-walk. Story picks up after supported exits and battles.
- Adjust beacon, wall, NPC and interactable audio from Accessibility Options in the System menu.
- Play with mod speech and recorded movie and scripted-scene descriptions in all eight game text languages.

## Install and controls

Install the [Microsoft .NET 9 Desktop Runtime for Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/9.0). Install the beta from Buu's Mods in [Accessibility Mod Manager](https://github.com/RealAmethyst/AccessibilityModManager), or extract the Windows ZIP into the Steam game folder. The downloads include the loader and description audio. Start your screen reader and launch the game from Steam.

Press **F10** for help. For field navigation, hold **RB/R1** and use the D-pad. Click the left stick for the beacon or the right stick for auto-walk. The keyboard equivalents use **Home/End**, **Page Up/Page Down**, **Delete** and **Right Shift+Delete**.

## Beta coverage

NVDA testing and copied-save Xbox controller replays covered field routes, combat handoffs and the route through the Crystal Tower to the White Teleport Portal. The complete final fight-to-credits sequence and some optional pickups still need live testing. For a route report, include the area, selected target and last announcement.
