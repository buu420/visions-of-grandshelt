# Visions of Grandshelt 0.2.57 beta

This update supports FINAL FANTASY RESONANCE on Windows Steam build 24250053.

- Displayed subtitles are spoken during voiced dialogue and movies in French, German, Spanish (Spain), Japanese, Korean, Simplified Chinese and Traditional Chinese. Use the game's Text Language setting to choose the subtitle language.
- The Earth Shrine save point appears in the scanner from the merchant's position. Auto-walk uses the clear lane around the merchant and approaches the entrance through the doorway. Manual guidance recalculates from your position when you go off-route.
- Item and skill descriptions, equipment stats, and displayed shortcuts such as Quick Heal are read in menus. Recovery names the highlighted party member.
- In Quests, use Page Up and Page Down or the right stick to scroll and hear the passage in view. F5 rereads the current passage.

## Update

Close the game. In [Amethyst Accessibility Mod Manager](https://github.com/RealAmethyst/AccessibilityModManager), choose **Visions of Grandshelt** from **Buu's Mods** and select **0.2.57 Beta**. For a manual update, extract the Windows ZIP into the Steam game folder. Both packages include Reloaded, Prism, and the audio description assets. The game-local loader requires the [Microsoft .NET 9 Desktop Runtime for Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/9.0).

For a manual upgrade from 0.2.52, see the [instructions for removing the retired recordings](https://github.com/buu420/visions-of-grandshelt/releases/tag/v0.2.54).

## Beta testing

On copied saves, controller auto-walk reached the save point and entered the Earth Shrine from two starting positions. Manual guidance recalculated after a deliberate detour. The copied game sent French and Japanese movie subtitles to NVDA. Live route testing for these changes covered the Earth Shrine exterior.

If you encounter a problem, include your game text language, area, target or scene, and the last announcement in [GitHub Issues](https://github.com/buu420/visions-of-grandshelt/issues).
